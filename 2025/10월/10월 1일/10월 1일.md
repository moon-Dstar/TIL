## JavaScript

### function
- 함수 실행 컨텍스트
- Lexical Scope: 함수가 선언된 위치가 상위 스코프를 결정한다. (JavaScript)
- Dynamic Scope: 함수가 실행한(호출) 위치가 상위 스코프를 결정한다.
- var: 공용함수 => 함수 레벨 스코프만 적용
- let, const: 함수레벨, 블록레벨 스코프 모두 적용
### oop
- 리터럴 형식 객체 사용 => 1개의 객체 생성
- 생성자 함수 기반 => 여러개의 객체 생성 목적
- class 기반 객체지향 프로그래밍
### event
- 이벤트 리스너 방식
